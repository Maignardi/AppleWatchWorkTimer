# ⌚ WorkTime for Apple Watch

**A standalone watchOS app that tells you exactly when your workday ends.**

Set the time you arrived and how long your shift is, tap **Calculate**, and the watch shows the time you can leave. Your values are saved, so they are still there the next time you raise your wrist.

## ✨ Features

- Pick your **arrival time** and **shift length** with wrist-friendly hour and minute pickers
- One tap to **calculate your clock-out time**
- **Persists** arrival, shift and result with `UserDefaults`
- **Reset** to start a new day
- Runs fully on the watch, no iPhone companion required

## 🧰 Tech stack

Swift · SwiftUI · watchOS · `UserDefaults`

## 🚀 Getting started

1. Clone the repository and open the project in Xcode.
2. Select the **WorkTime Watch App** scheme.
3. Run it on an Apple Watch simulator or a paired device.
